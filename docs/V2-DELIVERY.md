# Zero 博客版本二交付说明

日期：2026-10-24（Asia/Shanghai）；版本：v2.0.0。

## 1. 现状勘察

- 服务器：Alibaba Cloud Linux 3；生产博客由 Docker 管理。
- 应用容器：`wordpress`，Apache / PHP 8.3.35，WordPress 7.1.3（实际文件读取）；数据库容器：`wpdb`，MariaDB 11。
- 活动主题：Argon 1.3.5；无已启用的普通插件。
- URL 使用 `?p=ID` / `?cat=ID` 形式，原主题提供 PJAX、侧栏、搜索、评论表单和代码高亮。
- 5 篇已发布文章；检查了 89 条非 revision 内容记录。
- 原美化由约 35.5 KB 页脚内联代码和约 13.1 KB Additional CSS 叠加，飘花、点击动画、加载提示等默认开启。
- 原站与本次实现均未发现看板娘；新实现没有任何人物桌宠、Live2D、2D 看板娘或相关依赖。

## 2. 备份与变更策略

首次修改前创建 `/opt/wordpress/backups/beautify-20261024-1125/`，包括完整站点文件（约 62 MB 压缩）、数据库 SQL（约 360 KB 压缩）、Compose 和镜像标识；压缩校验和 SHA-256 校验通过。

所有线上迭代文件在替换前均备份到该目录，采用临时文件 → `mv` 更新。生产没有改动父主题、WordPress 核心、文章正文、评论或真实部署配置；访问测试会正常更新原主题的浏览统计或缓存。

使用 MU 插件增强层，只对已识别的旧 Zero 样式输出做过滤，原数据库值保留。换用非 Argon 主题时自动不加载增强层。

## 3. 视觉方案

- 樱粉与雾蓝只用于装饰与按钮点缀；正文使用高对比深灰 / 月夜浅色字。
- 原创 3.6 KB 静态 SVG 樱花湖景：纯本地、无人物、无外部插图下载。
- 桌面首页最新文章强调卡片 + 两列列表；移动端单列；图片与标题分离，标题不叠在封面上。
- 修复原主题负边距导致的标题裁切；长标题自动完整换行。
- 导航默认实色，搜索图标跟随配色；桌面用原生按钮，移动端采用原生 CSS 图标。
- 桌面正文 17px / 行高 33.15px；移动端正文 16px / 行高 31.2px。
- 系统字体，中文优先 PingFang / Microsoft YaHei 等本机字体；不下载 Web 字体。
- 表格与代码支持容器内水平滚动，图片最大宽度 100%。保留原主题搜索、评论及代码高亮。

## 4. 特效开关

| 配置键 | 效果 | 默认 | 性能 / 可读性限制 |
|---|---|---|---|
| petals | 横幅樱花飘落 | 关 | 只绘制横幅背景；桌面 14 / 手机 5 个；DPR≤1.5；≤30fps；横幅出屏暂停 |
| clickStars | 空白处点击星光 | 关 | 精细指针；不作用于正文、侧栏、表单或交互控件；自动回收节点 |
| cardLift | 文章卡片轻悬浮 | 关 | CSS class 独立切换；非触屏 |
| heroGlow | 横幅柔光呼吸 | 关 | 只在启用时运行 CSS 动画 |
| glassNav | 导航磨砂玻璃 | 关 | 不支持 backdrop-filter 则使用实色 |
| readingProgress | 文章阅读进度 | 关 | 仅文章页；滚动合并到一帧；停用删除监听 / 观察器 / 节点 |

统一入口：访客右下角「阅读偏好」，站长后台「设置 → Zero 二次元美化」。

本地存储键：`zero-anime-effects-v2`、`zero-anime-mode-v2`。不继承旧版默认开启的特效；仅兼容旧版配色偏好。恢复站点默认会移除访客特效覆盖。

动态特效在减少动态效果、省流量模式及后台标签页中暂停；阅读进度在减少动态效果时仍可作为功能性标识使用。模块通过按需 `import()` 加载，关闭后释放资源。无常驻默认 Canvas、进入遮罩、音乐、自定义指针或看板娘。

## 7. 性能结果与限制

首页 HTML 原始响应：112,551 → 64,947 字节（约减少 42.3%）。这是 HTML 减少，不是首屏全部网络资源减少 42.3%。新增基础 CSS/JS/静态 SVG 可被浏览器缓存；特效文件按需加载。

相同客户端各 5 次 curl 样本：TTFB 中位数 0.445 → 0.379 秒；样本很少且网络有波动，只能作为未发现明显服务端回退的参考，不能宣称长期性能提升。

未执行 Lighthouse / 真实移动设备电量评估、屏幕阅读器全站验收、完整浏览器兼容矩阵、自动化评论发布或破坏式灾难恢复；减少动态 / 后台 / 省流量分支已实现并代码检查，不宣称已进行真实系统偏好切换测试。
